# zxzx Fcitx5 Themes

三套深色、微透明、紧凑胶囊形 Fcitx5 主题，基于 macOS-dark（原作者 thep0y）修改。

| 目录 / Name | 配色 |
| --- | --- |
| `DustyRose[zxzx]` | 灰玫瑰 |
| `WeChatGreen[zxzx]` | 微信绿 |
| `GraphiteSilver[zxzx]` | 石墨银 |

本目录是统一 Git 仓库，只跟踪上述主题和仓库说明。`macOS-dark` 及其他目录被忽略，不纳入版本管理。
原先各主题的独立 Git 历史已移除；当前主题文件作为统一仓库的 `v1.0.0` 起点。

在 Fcitx5 经典用户界面中选择对应名称。修改主题后执行 `fcitx5-remote -r` 重载。
各主题 README 记录配色、字体尺寸要求和恢复方法。
